Atajos en VSCodium

Emmet es un sistema de abreviaciones integrado en VSCodium que expande fragmentos cortos tipo selector CSS en código HTML completo, permitiendo armar estructuras enteras con unas pocas teclas y un Tab, además de los atajos de teclado nativos del editor para moverte y editar más rápido.

Emmet — básico

  • ! + Tab → boilerplate HTML5
  • !!! + Tab → doctype solo
  • div.clase + Tab → <div class="clase"></div>
  • div#id + Tab → <div id="id"></div>
  • ul>li*5 + Tab → lista con 5 items
  • div+p+span + Tab → elementos hermanos
  • .container>header+main+footer + Tab → estructura anidada
  • nav>ul>li*3>a + Tab → nav con links anidados
  • img[src="x.jpg" alt="y"] + Tab → atributos custom

Emmet — numeración y texto

  • ul>li.item$*5 → numera automático (item1...item5)
  • ul>li.item$$*5 → con padding de ceros (item01...)
  • h$[title=item$]{Header $}*3 → numeración combinada
  • p{Hola mundo} → texto dentro del tag
  • a{Click acá} → link con texto
  • ul>li{Item $}*3 → texto + numeración

Emmet — agrupación y niveles

  • div>(header>ul>li*2)+footer>p → agrupación con paréntesis
  • div+div>p>span+em^bq → ^ sube un nivel (climb-up)

Emmet — inputs y forms

  • input:text, input:email, input:password, input:checkbox, input:radio, input:submit, input:date, input:number → variantes preconfiguradas
  • form>input:text+input:submit → form básico
  • select>option*4 → select con 4 opciones

Emmet — tablas

  • table>tr*3>td*3 → tabla simple 3x3
  • table>thead>tr>th*4^^tbody>tr*3>td*4 → tabla con thead/tbody (^^ sube dos niveles)
  • table>tr*3>td{Celda $}*4 → celdas con texto numerado
  • table>tr*3>td.col$*4 → clases numeradas por columna
  • table>caption{Mi tabla}+thead>tr>th*3^tbody>tr*2>td*3 → con caption
  • th[scope=col]*4 / th[scope=row] → accesibilidad
  • table>thead>tr>th*3^tbody>tr*3>td*3^tfoot>tr>td*3 → con tfoot

Emmet — lorem ipsum

  • p*3>lorem → 3 párrafos random
  • lorem10 → 10 palabras
  • ul>li*4>lorem3 → lista con lorem corto
  • table>tr*4>td*3>lorem2 → tabla con contenido de prueba

Navegación/edición multi-cursor

  • Ctrl+D → seleccionar próxima ocurrencia igual
  • Ctrl+Shift+L → seleccionar todas las ocurrencias iguales
  • Alt+Click → agregar cursor donde clickeás
  • Ctrl+Alt+↑/↓ → agregar cursor arriba/abajo (puede chocar con workspace switcher en MATE)
  • Alt+↑/↓ → mover línea arriba/abajo
  • Shift+Alt+↑/↓ → duplicar línea arriba/abajo
  • Ctrl+Shift+K → borrar línea entera

Comentarios

  • Ctrl+/ → comentar/descomentar línea o selección (línea por línea)
  • Shift+Alt+A → comentar selección en bloque (un solo <!-- -->)

Tags HTML

  • Shift+Alt+. / Shift+Alt+, → expandir/contraer selección de tag
  • Ctrl+Shift+\ → saltar al tag de apertura/cierre correspondiente

Autocompletado

  • Ctrl+Space → forzar sugerencias (puede chocar con IBus)
  • Ctrl+. → quick fix / acciones rápidas

Formato y bloques

  • Shift+Alt+F → formatear documento
  • Ctrl+K Ctrl+0 → colapsar todos los bloques
  • Ctrl+K Ctrl+J → expandir todos los bloques

General

  • Ctrl+` → togglear terminal integrada
  • Ctrl+Shift+E → foco en explorador de archivos
  • Ctrl+P → quick open (buscar archivo)
  • Ctrl+K Ctrl+S → editor de keybindings (para remapear atajos)
